# Validate Phase

Version: 0.1.0

---

## Purpose

Prove the implementation matches the contract before release.

---

## Accountable Owner

The Validate phase must have a designated Accountable Owner before work begins.

The Validate Accountable Owner is responsible for ensuring the implementation, orchestration, tests, edge cases, and failure behavior are checked against the contract.

The Accountable Owner may delegate review, testing, evidence gathering, or correction work. Accountability for completing the phase remains with the Accountable Owner.

---

## Responsibilities

- Compare implementation against the contract
- Verify protocol conformance
- Verify orchestration follows approved flow
- Check success paths, failure modes, and edge cases
- Review available test results
- Identify mismatches, risks, and required corrections

---

## Inputs

- Approved contract document
- Protocol definitions
- Architecture plan
- Implementation
- Test results, if available

---

## Outputs

- Validation report
- List of mismatches, gaps, and risks
- Required corrections or release recommendation

---

## Exit Criteria

- Contract requirements are verified
- Success behavior is verified
- Failure behavior and edge cases are verified
- Any mismatch is corrected or explicitly documented
- The system is ready for the Release phase

---

## Completion Celebration

The Validate phase is complete when the team can say:

> It matches what we promised.
